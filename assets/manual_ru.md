# Просмотр шрифтов — руководство

## Страница «Шрифты»
1. В списке показаны все шрифты компьютера в их собственном начертании.
2. Введите любой текст в поле **Текст образца**, ползунком **Размер** меняйте кегль.
3. Каждый шрифт проверяется автоматически: **Латиница** зелёная: есть `ʻ` (U+02BB) и `ʼ` (U+02BC);
   **Кириллица** зелёная: есть `Ў ў Қ қ Ғ ғ Ҳ ҳ`. Результат кэшируется.
4. Фильтр «Узбекский полностью» оставляет только шрифты с полной поддержкой обеих письменностей.
5. **Тип**: моноширинные, пропорциональные или символьные.
6. Выберите шрифт — справа появятся крупный образец, начертания и состояние каждой узбекской буквы.
7. Кнопки: **В избранное**, **Копировать имя**, **Открыть расположение**, **В сравнение**, **Сохранить PNG**.

## Страница «Сравнение»
1. **Количество шрифтов**: 2–4.
2. В каждой ячейке выберите шрифт (можно искать по имени).
3. Измените текст и размер — обновятся все ячейки.
4. **Сохранить PNG** — сохраняет таблицу сравнения как изображение.
