# Font Showcase — user guide

## Fonts page
1. The list shows every font on your computer rendered in its own typeface.
2. Type any text in **Preview text** and change the size with the **Size** slider.
3. Every font is checked automatically: **Latin** is green: has `ʻ` (U+02BB) and `ʼ` (U+02BC);
   **Cyrillic** is green: has `Ў ў Қ қ Ғ ғ Ҳ ҳ`. Results are cached.
4. The "Full Uzbek" filter keeps only fonts that fully support both scripts.
5. **Type**: monospace, proportional or symbol fonts.
6. Select a font to see a large sample, its styles and the status of each Uzbek letter on the right.
7. Buttons: **Favourite**, **Copy name**, **Open file location**, **Add to compare**, **Export PNG**.

## Compare page
1. **Number of fonts**: 2–4.
2. Pick a font in each cell (type to search).
3. Change the text and size — all cells update together.
4. **Export PNG** saves the comparison grid as an image.
